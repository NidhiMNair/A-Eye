# Real Samples Directory

Place real test image files (`.jpg`, `.png`) and video clips (`.mp4`, `.avi`) recorded from smartphone cameras here for offline pipeline validation and fine-tuning.

## Guidelines
- Do NOT commit large binary files or private user video recordings directly to version control.
- Supported image formats: JPG, PNG.
- Supported video formats: MP4, AVI (1080p or 720p at 15–30 FPS recommended).
- Organise recordings by session ID if testing WP1.6 dataset converters (e.g. `real_samples/session_001/frame_0001.jpg`).
